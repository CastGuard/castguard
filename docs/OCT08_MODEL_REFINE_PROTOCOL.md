# 10/8 모델 탐색 2차 등록 — test 개봉 전

1차 128개 후보의 validation 결과를 확인한 뒤, 아직 test를 평가하지 않은 상태에서 2차 탐색을 등록한다. 기존 모델 탐색 프로토콜의 성공 기준/선택 목적함수/분할/지연회신/내부 early stopping/마감은 그대로다. 1차 후보와 설정 파일은 보존한다.

가설: 1차의 신경망 검증 AP 상승을 더 넓은 폭/깊이/학습률/규제로 확인하고, 트리 후보의 좁은 규제 범위를 확장하면 추가 이득이 있을 수 있다. 1차 최고 TabM의 within 검증 AP +.01739, 포착 +.02685는 기존 문턱(+.02/+.05) 미달이며 미래 평균 AP차는 음수다. 이 결과를 성공으로 바꾸지 않는다.

후보: S_FB와 SH_FB 각각 XGBoost/CatBoost/LightGBM 16설정, MLP/TabM 12설정. 총 144개 추가 후보, seed17×기존 5fold=720 fit. 고정 난수202610081. 정확한 목록 configs/oct08_model_refine.json은 실행 전에 등록한다. 트리는 더 낮은/높은 규제와 깊이/학습률/양자화 bin을 탐색하고, CatBoost Ordered/Plain을 포함한다. 신경망은 폭64–512, 깊이1–4, dropout0–.5, batch128–512, 학습률/weight decay 로그 범위를 탐색한다. TabM head16/32, 기본/LinearReLU 수치 임베딩을 비교한다.

1차128+2차144 전체에서 원래 규칙대로 모델군별 하나를 선택한다. seed29/43 확인, 사전 정의한 평균 앙상블, validation 선택 봉인, 이후 test 평가 순서를 유지한다. 추가 adaptive validation 탐색이므로 검증 점수에도 선택 편향이 있을 수 있음을 명시한다. test 점수를 보고 3차 탐색을 이어가지 않는다. 기존 제출물/판독기는 수정하지 않는다.
