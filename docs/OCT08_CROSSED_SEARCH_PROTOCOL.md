# 10/8 모델 × 데이터 조합 교차 실험

사용자가 지적한 누락을 보완한다. 직전 현대 모델 탐색은 S/SH 및 피드백 층만 비교했고, #40 포함 네 조합 전체를 현대 모델로 교차하지 않았다. 당시 baseline은 기존 S_FB 판독 모델이었으며 순수 #42 현재 입력 기준과 혼동해서는 안 된다. 제출 파일/제출 문구는 수정하지 않는다.

## 기준과 요인

- B0 주 기준: #42 현재 공정·센서·제품종류 21변수(S)만 사용하는 고정 LogisticRegression(C=.3), 피드백 없음. S의 예측 입력에 #41 이력/#40 전이/과거 검사 정답이 없다. 비교 행과 기존 분할을 보존하기 위해 이미 구축한 #41 연결 코호트는 그대로이며 완전히 새 #42 모집단이라고 주장하지 않는다.
- 강한 단일 데이터 기준: 동일한 튜닝 예산으로 선택한 S의 각 모델군 및 S 내부 앙상블. 모델 변경 효과와 데이터 추가 효과를 분리한다.
- 기존 운영 참조: S_FB logistic은 별도 표기. FB는 과거 #42 검사결과를 사용하고 20개 공정 event 시계는 #41 전체 timeline에 의존한다. 이를 엄격한 #42-only로 부르지 않는다.
- 4조합 S(#42), SH(#42+#41 과거이력), S_T(#42+#40 전이), SH_T(세 데이터). 각각 FB 없는 주 실험과 FB 있는 보조 실험으로 분리해 총8입력. 원시 데이터 무작정 병합/현재 정답/shot_position 금지.
- #40 전이 방식은 앞 실험의 5변수 proxy mapping과 train-only ECDF 및 RF 점수1개를 유지한다. 물리적 의미·단위 동등성 미확인 가정이다. source RF seed17을 한 번 학습해 모든 target seed에 고정하여 target 모델 변경 효과를 분리한다. target ECDF는 outer train에만 fit하고, early stopping 내부에서는 purged inner-fit에 다시 fit한다.

## 동일 탐색 예산

이전 두 탐색에 등록된 모든 고유 설정을 그대로 사용한다. XGBoost/CatBoost/LightGBM 각24, MLP/TabM 각16, 고정 RF1 및 logistic1: 총106설정×8입력=848후보. 신규 hyperparameter 범위나 test 성능에 따른 선택은 없다. seed17×기존5fold=4,240 outer fit(일부 동일 기존 모델은 입력/설정/코드 일치 확인 후 계산 캐시로 재사용). 실제 새 실행과 캐시 재사용 수를 구분한다.

각 (모델군,입력)에서 validation 목적함수 .5×within AP +.5×forward4fold 평균AP가 최고인 설정을 선택한다. 동일 후보끼리 목적함수 baseline 상수는 순위에 영향을 주지 않는다. 동률은 within AP 후 ID. 또한 각 모델군의 S와 S_FB에서 선택한 설정을 다른3조합에 그대로 적용하는 고정-설정 비교군을 사전 지정한다. 이들의 seed29/43도 학습한다. 따라서 (a) 같은 설정의 데이터 추가 효과, (b) 각 조합을 동일 예산으로 튜닝한 성능을 모두 볼 수 있다.

각 입력 안에서 7모델군의 3seed 평균, 두 모델 가중치 .25/.5/.75, logistic 제외 6모델 평균, 전체7모델 평균을 비교(입력당72개). 데이터 구성이 다른 모델끼리 섞지 않는다. 주 최종 후보는 FB 없는4입력에서 validation만으로 선택하며 FB 층은 별도 후보로 표시한다. 앙상블 선택 후 구성·threshold·모델해시를 봉인하고 재사용 test를 평가한다.

## 성과 판정

B0 개선과 강한 S 기준 개선을 각각 계산한다. 다종 데이터 추가가치 채택 기준은 원래 within validation AP+.02, 상위20%검사 포착+.05, 미래 validation 최소2fold에서 두 지표 비감소. 비교하는 두 모델의 입력 외 설정을 고정한 표와 독립 튜닝 표를 구분한다. FB 층은 S_FB 강한 기준을 사용한다. #42 자체 모델이 좋아진 효과를 다종 융합 효과로 세지 않는다.

AP/AUC/Brier, TP/FP/FN/TN/FPR, 상위20% 포착/정확한 분모, 3seed 점수, within6run paired bootstrap1000회 기록. 테스트는 이미 여러 번 노출됐고 후보 설정도 과거 validation에서 탐색됐으므로 탐색적 재사용이다. 과거 test를 본 이력을 봉인으로 없앨 수 없다. 이번 test 결과를 보고 재선정하지 않는다.
