# 회차6 단순 기준과 심사 주장 검토

2026-10-03 KST 실행 전 고정. 기존 결과를 이미 본 뒤 요청된 설명용 비교다. 새 독립 검증 또는 사전 확증 실험이 아니다. 학습 모델·과거 결과·선택·임계값을 변경하지 않는다.

고정 조건: 기존 회차3 바깥 개발4구간, 전체3,395행·품질정답2,879행·양성505 Shot, 전체20% 누적 검사 용량, 과거 슬롯 이월 금지, 동일 입력결손 hold FIFO, 동일 품질점수 가용 mask. 마지막 mask는 #42 파일에 관측된 행에 한정되는 현재 구현의 범위다. 실제 전체 생산 흐름에 센서가 실시간 제공되는지 확인되지 않았다.

비교4종: (1) 동점 FIFO, (2) 독립 균등 난수 위험도 seed1000~1099의100회 평균/범위, (3) nested fit의 마지막100개 품질관측에서 제품코드별 양성빈도, 없는 제품은 같은100개의 전체빈도, (4) fit14공정값의 중앙값과 IQR에서 평균 절대 이탈. 학습구간 중앙값으로 결측 대체, IQR0은1을 사용한다. (4)는 단위 없는 경험 규칙이며 인증된 현장 공정 규칙이 아니다. 임계값이나 방향을 결과에 맞춰 바꾸지 않는다.

최근빈도는 fit 시점에 고정한다. 실제 검사 결과 도착시간이 없으므로 평가 중 품질정답을 즉시 받는다고 가정하거나 갱신하지 않는다. fit100은 비교 편의를 위한 사후 정의된 고정 설명 기준으로, 최적 창 길이라고 주장하지 않는다.

모든 정책의 점수 생성과 queue 입력에 평가 라벨·상태 정답을 넣지 않는다. 검사 후 고정 정답과 대조해 같은 모집단의 포착·정상부담·보류·실제검사량을 보고한다. 전역 상위20%나 단순20% 기대와 인과적queue는 별개다. 무작위100회 분포는 고정자료에서 정책 난수의 변동이며 미래 일반화 신뢰구간이 아니다.

성공 조건은 유리한 점수 획득이 아니라 누수·예산·분모·재현 검사를 통과한 전체 결과 공개다. 실패/열세인 기준도 생략하지 않는다. 결과로 Q/GQ를 바꾸지 않는다. 입력/원천 해시가 달라지거나 입력에 정답이 섞이면 중단한다. 추가모델·하이퍼파라미터 탐색은 하지 않는다.

구현 검토 기록: 첫 계산의 난수 생성기가 fold마다 같은 seed를 다시 써 구간 간 난수열을 공유했다. 첫 결과는 `baselines/`에 보존하고, `[반복 seed, fold]`로 구간별 난수열을 분리한 `baselines_final/`을 최종 설명용 비교로 사용한다. 반복100회·정책·창길이·검사조건은 변경하지 않는다. 성능에 유리한 시드나 정책을 선택하는 수정이 아니다.
