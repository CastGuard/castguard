## 현장 가치 관점에서 추가 확인한 사실

현재 예측에서 위험도 상위 20% Shot을 검사한다고 가정하면, within_run A는 불량의 평균 **29.19%**를 포착한다(무작위 검사 기대 약 19.97%). 같은 예산의 관측 포착률이 무작위 기대보다 높지만, 실제 비용·현장 가치는 확인되지 않았고 관측 불량 대부분을 놓친다.

forward_run A의 포착률은 구간 2/3/4/6에서 **0% / 14.55% / 19.66% / 21.57%**다. 무작위 20% 검사보다 일관되게 낫지 않다. 구간 2의 불량은 5개뿐이라 불확실성이 크다. 이 계산은 고정 시험 결과의 사후 진단이며 새 모델 선정이나 현장 개선 효과를 입증한 실험이 아니다.

## 심사 기준으로 본 병목

저장소 공고문은 기업문제·통합 20점, AI 모델·통합성능 35점, 영향요인·오류분석 15점, 현장 적용 10점, 창의성·확장성 10점, 코드·재현성 10점이다. 이는 배점이며 우리 예상 득점이 아니다.

E만 강조해도 해결되지 않는다. E는 같은 #40 안에서 입력을 제거한 실험이다. 다종 데이터 연계가 실제 품질/의사결정에 주는 이익은 별도로 증명해야 한다. **기존의 "B 실패 → C+E를 핵심으로 전환" 결정을 철회한다.** `reports/oct02/RESULTS.md`와 `decision.json`의 해당 문장은 당시 결정 기록이며 현재 제출 전략이 아니다. 원래 측정·판정의 이력을 보존하기 위해 결과 파일을 소급 수정하지 않는다.

### 2. 10/3까지 실행할 두 가지 핵심 실험

두 실험의 **첫 후속 회차는 완료**했다. Q1은 Short_Shot만 실행했고 개발 실패, G1은 오경보 감소에도 목표 미달이다. 다른 Q1 유형은 학습하지 않았다. I1의 중첩 개발 운영 비교는 회차3에서 완료했으며 순효과 채택에 실패했다. [등록한 비교·표본·채택·중단 기준](EXPERIMENTS_NEXT.md)에 따라 실험과20:00 비교표 확인을 완료했고 회차8에서22:00 이전 축소 판정을 기록했다. 개발 후보 수를 제한하고 이미 본 test에 맞춘 추가 탐색은 하지 않는다.

**품질: 어떤 불량/제품에서 실제로 도움이 되는지 좁힌다.** 불량유형·Product_Type별 표본 수와 라벨 분포를 먼저 확인한 뒤, 충분한 양성 표본이 있는 유형을 대상으로 제한된 모델 비교를 수행한다. 기존 전체 불량 모델과 동일 검사 예산(10/20/30%)에서 포착률·누락률을 비교한다. 유리한 유형만 전체 성과처럼 보고하지 않으며, 표본이 부족한 유형은 평가 불확실성을 공개한다.

**Gate: 낮은 오정지에서 탐지하는 문제로 모델/임계값 선정 목적을 맞춘다.** validation의 AP만이 아니라 가동구간별 정상 FPR 제한과 에피소드 포착률을 함께 보고 선택한다. 필요한 보정과 보수적 임계값은 train/validation에서만 정한다. 기존 test는 재사용된 평가임을 표시하고, 미래 구간별 경보 부담과 최악 구간을 같이 공개한다. 단순 공정 규칙/기존 모델 대비 이익이 없으면 핵심 솔루션에서 내려놓는다.

이미 모든 고정 test를 열어본 상태다. 이후 성능 상승을 새 독립 검증의 증거처럼 표현하지 않는다. 내부 모델 선택은 train 내부 시간분할/기존 validation에서 하고, 추가 외부 데이터나 미사용 시점 확보 여부를 확인한다. 새 독립 데이터가 없다는 한계는 최종 제출물에도 남긴다.

### 3. 10/3 종료 판정: 범위 축소

회차8에서 아래 세 번째 분기를 채택했다. Q1/G1/I1의 실패/부분 근거와 회차7 진단을 근거로 현재 데이터 적용 한계·검사 의사결정·새 수집 요구로 좁힌다. 다른 데이터로 전환할 원본/권한/연계/평가 요건은 확보되지 않았다. 아래 조건문은 원래 판단 기준이다.

- 특정 불량·제품에 재현 가능한 검사 가치가 있으면 그 기업문제를 중심으로 주제를 좁히고, 해당 범위에서 보조 데이터 연계의 이익을 검증한다.
- 낮은 오정지 조건의 Gate가 검사/경보 효율을 개선하면 의사결정 단계 융합을 핵심으로 한다. 검출 수와 정상 생산의 부담을 함께 제시한다.
- 둘 다 근거가 부족하면 #42 전체 공정에서 성능 개선에 성공했다는 서사를 내려놓고 적용 한계·검사 정책·수집 요구 중심으로 범위를 축소한다. 신규 데이터 전환은 **10/3 종료까지 출처·원본·연계·라벨·분할을 확보하고 10/4 정오까지 비교를 끝낼 수 있을 때만** 허용한다. #40의 높은 AUC만 보고 주 데이터 이름을 바꾸는 것으로 융합 요구를 충족했다고 간주하지 않는다.
- I1의 중첩 개발 운영 비교를 회차3에서 완료했다. 추가 경보·보류 검사량도 용량에 포함하면 품질 포착의 순이익을 확인하지 못했다. 융합 성공 주장을 채택하지 않으며, 추가 후보 탐색보다 외부 계보와 운영 제약을 확인한다.

## 실험 후 계획을 바꾸는 규칙

앞으로 새 실험과 의미 있는 작업을 마칠 때마다 이 문서의 목표표와 다음 결정을 점검한다. 변경이 없으면 일지에 변화 없음을 남긴다. 고정 목표값을 결과에 맞춰 낮추지 않고, 목표를 바꿀 때는 기업문제·검사 예산·비용 근거와 변경 이력을 남긴다. 일지는 `docs/daily/YYYY-MM-DD.md`에 회차별로 기록하며 예약 자동화는 사용하지 않는다.

1. 어떤 심사 항목과 가설을 검증하는 실험인지 정한다.
2. 성공 조건과 중단 조건을 결과를 보기 전에 기록한다.
3. 결과를 **목표 달성 / 일부 근거 / 실패 / 미측정**으로 판정한다.
4. 다음 실험·버릴 주장·유지할 주장을 갱신한다. 작업 횟수나 테스트 수를 목표 성과의 대용으로 쓰지 않는다.

원래 대상권 ROC-AUC .75, AP 불량률 2.5배 등은 야심찬 내부 목표로 유지한다. 주제 범위를 좁힐 경우 그 범위의 기준값과 비교 대상을 새로 명시한다. 현재 확보한 근거만으로 "이대로 진행하면 1등"이라고 판단하지 않는다.
