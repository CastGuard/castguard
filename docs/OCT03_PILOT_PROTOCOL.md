# Q1 Short_Shot / G1 첫 개발 비교

2026-10-03 KST. 원본 `JH` 작업을 보존한 별도 snapshot에서 실행한다.
원래 4유형 계획 중 미래 validation 2개 이상 표본 지원이 있는 Short_Shot만 먼저 수행한다.
다른 3유형 결과를 성공/실패로 대신 판정하지 않는다. 표본 감사는 원래 기준 그대로다.
기존 test는 이미 공개되었다. 이번 모든 결과는 탐색 연구이며 독립 확증이 아니다.

## 실행 전 고정

- 설정: `configs/oct03_pilot.json`; 원래 학습 설정: `configs/oct02.json`.
- Q1: A 입력, 로지스틱/LightGBM, 5 seed, 등록 표본 하한을 충족한 9fold, 최대 90회.
- 전처리와 라벨은 train에서만 학습. 미래 test는 개발 함수/후보 선택에 전달하지 않는다.
- baseline은 기존 A 모델의 전체 불량 validation AP로 선정된 모델군과 원래 예측이다.
- 전문 모델군은 각 fold의 validation Short_Shot 포착률@20%의 5seed 평균 최대,
  동률은 Short_Shot AP 평균, 모델명 순으로 결정한다. 다른 fold의 선택을 가져오지 않는다.
- 검사는 점수 내림차순, 동률 row_id 오름차순의 상위 floor(n*b)개다. b=10/20/30%.
- Short_Shot과 전체불량 포착/누락, 실제검사율, lift, 분모를 함께 기록한다.
- Q1 다음 단계 조건: 적격 전체fold와 forward 각각의 평균 개선 >=5%p,
  forward 적격fold >=2, 각 forward 평균 개선 >=0, 무작위 기대보다 평균 포착률 높음.
  전체fold는 같은 validation run을 재사용하므로 독립 표본으로 해석하지 않는다.
- paired 불확실성은 모델 재선정 없이 고정한 검사 지시자의 capture 차이다.
  평가에 2개 이상 run이 있으면 run 단위 재표집, 단일run은 시간순 20행 이동 블록.
  5seed 결과는 먼저 행별 검사 지시자 평균으로 합친다. seed를 독립 표본으로 부풀리지 않는다.
  각 적격 forward 구간의 조건부 95% 구간이 0을 포함하면 `일부 근거`로만 판단한다.
  선택에 쓴 validation 구간의 bootstrap이므로 선택 편향/새run 불확실성을 해결하지 못한다.

## G1 고정 정책

1. 기존 AP 선정 모델/기존 pooled FPR 2% 임계값.
2. 기존 4개 모델의 validation 예측 재사용. seed별 모든 관측run의 정상 FPR<=2%인
   threshold 중 에피소드 탐지 최대, 탐지 지연 최소, threshold 최대 순으로 고정.
   모델군은 5seed 평균 탐지율, 평균 탐지 지연, 평균threshold, 모델명 순으로 선택.
3. train만 이용해 현재 공정 14변수/양·음 방향의 단변량 AUC 최대 규칙을 선정.
   동률은 변수명, 방향(+ 우선) 순. 경계는 validation의 정책2 기준으로만 선정.
   규칙은 결정론적이며 5seed 행은 비교를 위한 반복 표기다.

G1 에피소드 지연은 실제 Shot 번호 차이이며, 입력 결손 예열을 포함한 전체 에피소드
시작점부터 계산한다. 관측가능/전체 에피소드, 정상관측 분모, 결손 보류를 구분한다.
validation 관측 에피소드가 2개 미만이거나 정상 근거가 없는 run은 판정불가/무경보다.
제약 내 모든 후보가 탐지0이면 무경보 정책으로 명시하며 이를 탐지 성공으로 처리하지 않는다.
holdout/forward validation은 단일run이라 run별 제약 자체는 기존 pooled 제약과 동일하다.
구별되는 부분은 임계값의 에피소드 목적 및 모델군 선택이다.

## 평가와 중단

`develop`는 validation만 평가하고 후보 전체/선정/모델/해시를 저장한다.
`evaluate`는 고정 selection 파일 및 코드/입력/모델 해시가 동일할 때 빈 test 폴더에
한 번만 쓴다. Q1은 개발 수치 조건 통과 때만 기존 test에 적용한다. G1은 세 고정 정책을
한 번 비교한다. 평가 결과에 따라 모델/임계값을 다시 맞추지 않는다.

G1 최소 목표는 run_holdout 정상 pooled FPR<=2%와 관측 16/20 동시 탐지,
대상권 내부 목표 18/20과 평균 지연<=3이다. seed별/각run/최악run과 전체21 분모도 공개.
모든 seed의 최소 조건을 별도 보수적 판정으로 쓰고, 모든run의 2% 만족 여부를 별도로 표시.
단순 규칙에 비해 이익이 없으면 복잡한 모델의 현장 우위를 주장하지 않는다.
Q1 개발 실패 시 test를 열지 않고 원인을 기록한다. G1 평가 실패 시 자동 생산중지
주장을 기각하고 관측 불가능/구간 이동/표본 제약을 분석한다.

심사 대응: AI/통합성능35점의 기본효용과 오류분석15점에 해당한다.
Q1/G1 자체는 보조데이터 추가 전후 I1 성공 증거가 아니다. 별도 I1이 필요하다.
원래 AUC/AP 목표, B +.02, FPR2% 기준은 낮추지 않는다.
