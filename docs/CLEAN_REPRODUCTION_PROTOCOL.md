# 새 환경 재현 사전 계획 · 2026-10-03

목적은 최신 ZIP의 설치·저장 근거 재생·고정 설정 재학습 가능성을 확인하는 것이다. 기존 공개 test를 다시 사용하므로 신규 일반화 성능이나 모델 개선을 측정하지 않는다. 기존 데이터·설정·모델·결과는 수정하지 않는다.

1. 시스템 패키지를 상속하지 않는 Python 3.12 가상환경을 작업 공간에 생성한다. 공식 PyPI에서 기존 `requirements-lock.txt`의 29개 버전을 그대로 설치한다. 기존 개발 가상환경은 변경하지 않는다. 설치 기록에는 공급 URL·버전·배포물 SHA256을 남긴다.
2. 최신 ZIP의 해시·독립 지표·전체 회귀시험·8개 변이시험·저장 모델/예측 재생을 수행한다. 문서 생성 의존성도 별도로 설치하고 누락된 전이 의존성 버전을 명시한다.
3. 원본 3개 CSV에서 모든 전처리 값 및 고정 분할을 새 작업 디렉터리에 재구성한다. 기존 전처리/분할과 값·행·열이 모두 같아야 한다. 파일 직렬화 바이트와 nullable dtype은 비교 대상이 아니다.
4. 재학습 대상은 사전에 다음 2개로 고정한다: q42 / all / within_run / primary / A / seed17의 **logistic, lightgbm**. 로지스틱은 기존 기준 모델, LightGBM은 이 분할에서 과거 validation으로 선택된 모델이다. `configs/oct02.json`과 학습 코드는 원본을 그대로 사용한다. 후보·seed·분할·임계값 규칙·성공 허용오차를 결과에 따라 바꾸지 않는다.
5. train만으로 학습·대치·스케일링하고 validation으로 원래 방식대로 임계값을 정한다. 과거 validation/test의 시간 측정치를 제외한 모든 수치 지표가 절대오차 **1e-10 이하**여야 한다. LightGBM의 저장된 validation/test 2,034행은 행 ID·역할·정답·판정이 같고 확률/임계값 절대오차 **1e-12 이하**여야 한다. 로지스틱은 ZIP에 원래 행별 예측이 없으므로 지표 비교에 한정한다. 없는 예측 일치를 주장하지 않는다.
6. 불일치·설치 실패는 실패로 기록하고 원인을 조사한다. 성능을 맞추기 위한 하이퍼파라미터 탐색은 하지 않는다. 신규 출력 경로가 이미 존재하면 중단한다.

전체 1,015회 모델 학습은 이번 범위에 포함하지 않는다. 이 2회는 모델군/전체 분할의 완전 재학습 보증이 아니다. 기존 저장 모델 170개 재생과 결합해 제한된 계산 비용으로 실행 경로를 점검한다. Windows x64 / CPython 3.12에서의 결과를 다른 OS·CPU·Python 버전의 동일성으로 확대하지 않는다.

최종 기록에는 실행 명령, 정확한 버전, 설치 공급원, 실제 비교 수, 최대 오차, 소요 시간, 실패와 남은 외부 요건을 남긴다. 가상환경·wheel·Python·Microsoft Office·시스템 글꼴은 최신 ZIP에 넣지 않는다.
