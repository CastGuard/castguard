# 10/3 회차3: 조건 이탈·보류와 시간순 검사 대기열

실행 전 등록. 이번 방식은 **중첩 시간순 개발 검증**이다. 기존 forward fold2/3/4/6의
train 안에서만 모델·임계값·보류 정책을 선택하고, 기존 validation run1/2/3/4에서 평가한다.
이 validation은 과거 실험에서 이미 본 데이터다. 새로운 독립 검증이라고 부르지 않는다.
기존 test 역할의 데이터·예측·성능을 이번 실행의 선택/평가에 사용하지 않는다.
앞 회차의 holdout 구간2 실패는 조건 이동 가설의 계기일 뿐 특정 변수/경계를 맞추지 않는다.

## 중첩 분할과 모델

- outer train에 여러 run이 있으면 마지막 train run을 inner calibration, 이전run들을 inner fit으로 쓴다.
- outer train이 run0 하나인 fold2는 #42 행 순서 앞70%를 fit, 나머지를 calibration으로 나눈다.
  경계가 예열 에피소드를 자르면 해당 에피소드 직전으로 옮긴다. 경계 양쪽에 같은 에피소드를 두지 않는다.
- 품질/Gate 각각 로지스틱/LightGBM 기존 설정×5seed×4fold = 최대80회 학습.
  학습 변환은 inner fit만 사용. 선택 후 calibration을 포함해 재학습하지 않는다.
- 품질은 inner calibration 전체불량 AP 평균 최대 모델군, 동률 모델명.
- Gate는 calibration 정상FPR≤2% 아래 에피소드/지연/높은 경계의 순서로 seed별 threshold를 정하고
  모델군은 평균 에피소드 포착, 지연, 모델명으로 선택한다. 관측 에피소드2개 미만이면 무경보/판정불가다.
- 품질 입력은 기존A, Gate 입력은 기존m41_gate. 신규 feature 탐색은 하지 않는다.

## 조건 이탈과 후보 정책

조건 이탈 점수는 현재 공정14변수 전체를 쓴다. inner fit의 정상에서 열별1/99% 범위와 IQR을
추정하고 범위를 벗어난 거리/IQR의 최댓값을 사용한다. IQR=0이면 fit의 전체 범위, 그것도0이면
상수1로 나눈다. 단위 미확인이므로 이 점수는 공학적 고장 한계가 아니다.
경계는 inner calibration 정상의 상위1%/0.5%까지만 보류하도록 정한 두 후보다.

모든 정책은 입력 공정14개가 하나라도 결측이면 필수 보류를 요청한다. 설비상태 정답의
결측 여부는 예측/보류 입력으로 쓰지 않는다. 공정값이 있으면 정답 미상 행에도 점수를 낸다.
품질 score는 #42에 실제 입력이 존재하는 Shot에만 있고, 미관측 품질 정답을 만들지 않는다.

- Q: 입력결측 보류 먼저, 남은 예산은 품질 위험도 순 검사.
- GQ: 입력결측 보류, Gate 경보, 품질 위험도 순.
- OOD1/OOD05: 입력결측 또는 조건이탈 보류, 비보류 Gate 경보, 품질 위험도 순.
  OOD에서 Gate 경보를 끄더라도 해당 행은 보류/개입 및 비용에 남는다.

## 실제 처리량을 제한하는 시간순 모의실험

기록을 source_row 순서로 한 행씩 처리한다. 기록 i 도착 시 누적 floor(i×b)개까지 검사할
수 있으며 b=10/20/30%다. 미래 점수·미래 행 수를 보지 않는다. 검사 슬롯 시점에 현재까지
도착한 후보 중 보류(선착순), Gate 경보(위험도), 품질(위험도) 순으로1건을 처리한다.
같은 Shot은 중복 검사하지 않는다. 같은 우선순위·점수는 도착순/row_id 순이다.
잔여 보류를 무료로 제외하거나 처리했다고 가정하지 않는다. 모델 inference는 현재 Shot 완료 후다.
실제 벽시계가 없으므로 지연은 관측 기록 수와 Shot 번호 차이로 표시하고 분/시간으로 꾸미지 않는다.
검사1건당1/3/5분은 실측 아닌 인력 시나리오로 총 필요 인시만 계산한다.

## 선택, 전체 분모, 채택 기준

inner calibration에서 예산20%로 GQ/OOD1/OOD05를 비교한다. 보류 잔량이 GQ보다 늘지 않고
검사가 닿는 예열 에피소드 수가 줄지 않는 후보 중 품질 포착률 최대를 선택한다.
동률은 보류량 최소, 정책명 순. 선택은 outer 평가 전에 고정한다. Q와 GQ는 항상 대조군으로 남긴다.

각 정책에서 전체 타임라인 N, 알려진 정상/예열/상태미상, 자동 경보 FPR(전체정상 및 관측정상),
경보∪보류 정상 개입률, 자동 처리 coverage, 보류율·미처리 잔량, 검사 총량과 대상품질 포착률,
예열 자동탐지/검사도달(전체 및 관측 에피소드), 자동탐지·검사대기 지연을 함께 기록한다.
검사도달은 사람이 상태/불량을 완벽하게 판정했다는 실측이 아니므로 자동탐지와 구분한다.
품질과 상태의 서로 다른 정답을 하나의 정확도로 합치지 않는다.

최종 개발 채택에는 평균 품질 포착률이 Q와 GQ 모두보다5%p 이상 높고, 평가 가능한 각 outer
구간에서 두 대조군 대비 음의 차이가 없어야 한다. 보류 잔량·정상 개입률이 GQ보다 늘지 않고
검사도달 예열 에피소드가 줄지 않아야 한다. 같은 예산/전체 모집단에서 확인한다.
자동 Gate의 기존FPR≤2% 목표는 별도 유지하며 보류로 낮춘 자동경보율만으로 통과시키지 않는다.
실패 시 이번 구간에 맞춰 threshold/feature/정책을 재튜닝하지 않고 비용/coverage 한계를 기록한다.
